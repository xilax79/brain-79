# Release v0.11.0 — Core refactoring and hardening

## Summary

Completed Phase 10 architectural refactoring and hardening across five stages prior to public release:

- **Stage 1 — Correctness, concurrency, and transactional integrity**: lowercase section normalization and mixed-case self-healing in `core/navigation.py`; global lock hierarchy (`_transaction.lock` -> `_registry.lock` -> `_drift_manifest.lock` -> `INDEX.md.lock`) enforced by `OrderedFileLock` in `core/locks.py`; eliminated TOCTOU unlocked read window in `regenerate_index_navigation()`; complete Pass 3 rollback and transaction-scoped temp cleanup in `core/session_commit.py`.
- **Stage 2 — Centralized Git layer and error-handling hardening**: consolidated all `git` subprocess invocations into `core/git_ops.py` with `GitSessionCache`, `NotAGitRepoError`, and `GitTimeoutError`; eliminated silent fail-open paths in AST Guard C and Pass 2d; deep-copy safe `_PARSE_CACHE` in `core/frontmatter.py`.
- **Stage 3 — Security hardening**: repository containment enforcement (`is_relative_to`) before reading governed targets in `core/drift.py` and `core/ast_guards/`; blocked Git option injection in `core/update.py` and `core/git_ops.py`.
- **Stage 4 — Modular decomposition**: pluggable `core/ast_guards/` inspector registry, declarative `core/harnesses/` Tier 1 adapter registry driving `init_project.py` and `doctor.py`, configurable `create_mcp_server(profile="core"|"full")` with `--mcp-profile` CLI flag, and `ContextVar`-backed immutable `ProjectContext` in `config.py`.
- **Stage 5 — Verification and release parity**: bumped version to `0.11.0` per ADR-013 and ADR-017, synchronized repository templates via `brain79 update-project`, and verified full CI suite, strict lint, doctor, and clean `orient()`.
