# Changelog — v0.13.1

## Summary

`v0.13.1` resolves three integrity and version-skew defects identified during live `v0.13.0` sessions:

- **BUG-008 — `load_registry()` disk reconciliation (`core/navigation.py`)**: `load_registry()` compares cached `.navigation_registry.json` paths against `_scan_indexable_md_files(wiki_root)` and deterministically rebuilds from disk whenever articles are missing or stale deleted entries remain, without deadlocking on `_registry.lock` when called from `register_article()` or `regenerate_index_navigation()` and preserving read-only filesystem safety.
- **BUG-009 — `index_desync` organizational lint rule (`core/lint_organizational.py`)**: `check_index_desync()` compares on-disk indexable `.md` files against `INDEX.md` `## Quick navigation` links, surfacing missing or stale entries with actionable remediation `Run 'brain79 navigate --regenerate --rebuild'` (blocking under `lint --strict`) while leaving empty wikis and fixtures without `INDEX.md` unaffected.
- **BUG-010 — Symmetric protocol version skew detection (`core/orient.py`)**: `check_protocol_version_skew()` parses semantic versions symmetrically and emits an explicit warning when a stale long-lived MCP server/CLI runs an older version than the repository's `AGENTS.md` protocol marker, instructing the user to restart their MCP client/server or run `brain79 update`.
