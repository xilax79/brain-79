# Changelog — v0.13.0

## Summary

`v0.13.0` eliminates multi-developer Git merge collisions and lowers brownfield adoption friction:

- **Merge-conflict-free derived state**: `.navigation_registry.json`, `.drift_manifest.json`, and `.bootstrap_state.json` are git-ignored via `.brain-79/.gitignore` (`sync_wiki_gitignore()`) and deterministically rebuilt on demand (`rebuild_navigation_registry()`, `rebuild_drift_manifest()`, `brain79 navigate --rebuild`) without masking drift or weakening Guard A/C.
- **Deterministic `INDEX.md` Git merge driver**: 3-way `merge_index_files()` (`brain79 navigate --merge-driver %O %A %B`) wired via `.brain-79/.gitattributes` and local `.git/config` (`sync_git_merge_driver()`, `brain79 doctor --fix`).
- **Brownfield onboarding (`bootstrap --auto-map`)**: stdlib-only `core/auto_map.py` detects `pyproject.toml`, `package.json`, `Cargo.toml`, and `go.mod` boundaries (including nested `src/` layouts), ranks modules by Git churn (`git_recent_file_churn()`), and emits pairwise zero-overlap `applies_to` proposals across CLI and MCP.
- **Configurable enforcement tiers (`strict` / `balanced` / `advisory`)**: declarative `enforcement:` in `SCHEMA.md`, `--enforcement` on `brain79 init`, tier-aware guard downgrades in `session_commit.py` and `wiki.py`, `--fail-on-warnings` on `lint`, and tier visibility in `lint`, `orient()`, and `doctor`.
