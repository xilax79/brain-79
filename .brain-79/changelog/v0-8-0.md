# Changelog — Version 0.8.0 — Transitive drift and ripple guards

Phase 6.7 release implementing Merkle leaf manifest drift tracking, multi-hop transitive DAG propagation, 4-phase transaction commit pipeline, and Anti-Sprawl governance.

## Added

- **Merkle leaf manifest (`.drift_manifest.json`)**: Exact per-file modified, added, and deleted drift attribution with 64 KB chunk streaming and CRLF/BOM normalization.
- **Multi-hop DAG transitive drift propagation**: Memoized cycle-immune recursive drift bubbling from source files to leaf articles and umbrella articles.
- **4-phase `_transaction.lock` commit pipeline**: Atomic multi-file writes and session commits wrapped under `_transaction.lock` with Pass 2d Hard Session Ripple Gate (`unresolved_session_ripple`).
- **AST Guard C signature diff**: Python `ast` public signature inspection preventing false verification when public APIs change.
- **Anti-Sprawl Guard (`duplicate_governance_target`)**: Pre-flight validation blocking duplicate articles whose target files are subsumed by existing active articles unless `supersedes` is declared.
- **Unbounded Signal 1 context ranker**: Removed `top_n` truncation on `applies_to` candidate matches in `rank_context_articles()`.
- **Golden Blueprint reconditioning**: Complete self-wiki anchoring across 100% of `src/brain79/**/*.py` modules with 0 drift and clean organizational health.
