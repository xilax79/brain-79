# Changelog — v0.15.0

**Release date**: 2026-11-24

## Highlights

- **Read-only CI PR gate (`core/ci_check.py`, `brain79 ci-check`)**: added `run_ci_check()` and `CiCheckReport` with PR diff impact analysis, 1-hop active ADR surfacing, full structural + organizational lint parity, dual-tier enforcement (`strict` default in CI, `balanced`/`advisory`/`schema`), Markdown/JSON output, and `--summary-file` / `$GITHUB_STEP_SUMMARY` support.
- **Passive lifecycle hook runtime (`--lifecycle-hook <session-start|stop>`)**: added fail-open, ASCII-safe JSON handler for Claude Code (`claude`), Antigravity (`agy`), and Cursor (`cursor`) with `1 MB` stdin cap, `.git` walk boundary, and loop-immunity/non-normal termination guards.
- **Opt-in lifecycle hook adapters (`core/harnesses/lifecycle_hooks.py`)**: added `ClaudeHooksAdapter`, `AntigravityHooksAdapter`, and `CursorHooksAdapter` wired to `--install-lifecycle-hooks` on `init` and `update-project` (plus `--harnesses hooks`) and `brain79 doctor [--fix]` diagnostics.
- **Composite GitHub Action (`action.yml`)**: added reusable PR gate action with pinned `astral-sh/setup-uv@v10.4.0`, injection-safe `env:` inputs, `$GITHUB_OUTPUT` exports, and idempotent `<!-- brain79:ci-check -->` PR comments; integrated `brain79 ci-check --write-step-summary` into `.github/workflows/ci.yml`.
- **Git diff range & `git_ls_files()` hardening (`core/git_ops.py`)**: added `git_diff_range_names()` with option/range-injection guards and three-dot to two-dot fallback, and hardened `git_ls_files()` to raise `GitError` on non-zero exit.
- **25-command CLI superset**: expanded `WHITELIST` to 25 subcommands (`ci-check` CLI-only; `MCP_TOOLS` fixed at 9 tools per ADR-020).
