# Changelog — v0.16.0

**Release date**: 2026-11-24

## Highlights

- **Language-agnostic Guard C orchestrator (`core/ast_guards/orchestrator.py`)**: generalized `has_public_api_changes()` with 2 MB asymmetric size guard, symlink escape checks, `GitSessionCache` reuse, and metadata-only `find_spec` inspector discovery.
- **Optional `brain79[polyglot]` Tree-sitter engine (`treesitter_inspector.py`, `polyglot.py`)**: added `TreeSitterInspector` and collision-free qualified signature extractors for 10 parsers (`typescript`, `tsx`, `javascript`, `go`, `rust`, `java`, `c_sharp`, `php`, `ruby`, `bash`) alongside built-in `PythonInspector` while keeping core zero-dependency.
- **Read-only context budget telemetry (`core/stats.py`, `brain79 stats`)**: added `compute_stats()`, `estimate_tokens()`, and `brain79 stats` (`--format text|json`, `--task`, `--paths`, `--max-articles`) with zero filesystem mutations.
- **Doctor and CI polyglot diagnostics (`core/doctor.py`, `.github/workflows/ci.yml`)**: added AST guard capability summary in `binary_and_environment`, `ast_guards` warning on broken grammars, and cross-platform `jobs.test-polyglot` CI matrix (`BRAIN79_REQUIRE_POLYGLOT=1`).
- **26-command CLI superset and language-agnostic docs**: expanded `WHITELIST` to 26 commands (`MCP_TOOLS` fixed at 9) and updated `README.md`, `USER_GUIDE.md`, and `ARCHITECTURE.md`.
