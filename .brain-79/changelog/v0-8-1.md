# Changelog — Release 0.8.1: Living manuals, temporal decontamination, and codebase de-phasing

## Summary

Release `v0.8.1` establishes formal mechanical governance to prevent temporal milestone tags (`Phase X`, `Sprint Y`, `Milestone Z`, `WIP`) from contaminating living manuals and production code. It introduces the three-class document ontology, formalizes Chesterton's Fence for ADRs, establishes epocal changelog consolidation, and de-phases production source code comments.

## Key deliverables

### 1. Temporal decontamination linter rule (`lint_organizational.py`)
- Added `check_temporal_contamination` inspecting living manual ontologies (`features/`, `architecture/`, `product/`).
- Emits `temporal_contamination_in_title`, `temporal_contamination_in_summary`, and `temporal_contamination_in_heading` for milestone markers while exempting immutable audit folders and roadmaps.
- Emits `shipped_specification_title` when a shipped living manual retains "specification" in its title.
- Multilingual and false-positive safe: recognizes English and Spanish milestone terms while ignoring domain concepts like "Two-phase commit" and "4-phase transaction pipeline".

### 2. Three-class document ontology & Chesterton's Fence (ADR-018)
- **Class 1 (Immutable Audit Trail)**: `decisions/`, `changelog/`, `_raw/` are append-only; historical rationale is never destroyed. Superseded ADRs cost 0 tokens in daily work.
- **Class 2 (Living System Truth)**: `features/`, `architecture/`, `product/` are timeless, evergreen manuals describing how the software operates today.
- **Class 3 (Ephemeral Operational Transition)**: `handoffs/` are short-term transition notes purged on demand.

### 3. Line-by-line semantic codebase de-phasing
- Sanitized docstrings and comments across `src/brain79/` (`orient.py`, `session_commit.py`, `drift.py`, `navigation.py`, `wiki.py`, `context.py`) and root `AGENTS.md`.
- Converted historical ticket annotations (`Defect 1..5`, `P1.1`, `P0.5`, `R5`, `Pilar 6.1`) into timeless technical explanations.

### 4. Template synchronization
- Updated `generate_frontmatter_template()` in `frontmatter.py` to include `archived` in comments for all relevant document types.
