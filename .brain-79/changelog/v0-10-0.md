# Changelog — release 0.10.0: automated battle-testing, chaos fuzzing, and multi-repo gauntlet

Release v0.10.0 delivers Phase 9 of the industrial scale roadmap, introducing a cross-platform GitHub Actions CI matrix, multiprocess stress testing, deterministic fuzzing across six corpus classes, transactional Pass 3 session commits with automatic rollback, the five-archetype battle gauntlet with in-process latency budgets, and live-agent recovery smoke testing.

---

## Key additions and enhancements

### 1. Multi-OS CI matrix and cross-platform invariants
- Configures 9-cell GitHub Actions matrix across Ubuntu, macOS, and Windows runners for Python 3.11, 3.12, and 3.13 (`.github/workflows/ci.yml`).
- Pins major GitHub Actions tags (`actions/checkout@v4`, `astral-sh/setup-uv@v5`, `actions/upload-artifact@v4`).
- Standardizes checkout line endings via `.gitattributes` (`* text=auto eol=lf`).
- Adds real-OS tests in `tests/test_cross_platform_and_locks.py` covering Windows reserved device names, case collision prevention on case-insensitive filesystems, path whitespace and non-ASCII character handling, CRLF drift hashing parity, and Win32 file lock retries.
- Validates workflow integrity and doctor warning allowlists in `tests/test_ci_workflow.py`.

### 2. Multiprocess stress, chaos, and deterministic fuzzing
- Implements 8-process synchronized concurrency stress testing (`Barrier(8)`, 25 operations per worker) validating zero state corruption, zero orphan temporary files, atomic lock release, and zero torn writes on shared resources (`tests/test_chaos_and_fuzzing.py`).
- Implements POSIX SIGKILL process crash lock recovery.
- Implements deterministic stdlib fuzzing across six corpus classes (YAML shapes, hostile encodings, unicode surrogates, exact size boundaries, forbidden paths, and cyclic/deep graph chains).
- Strengthens core engine hardening:
  - Validates surrogate-free, UTF-8 encodability and rejects NUL bytes in `src/brain79/core/validation.py`.
  - Rejects non-string frontmatter keys in `src/brain79/core/frontmatter.py`.
  - Rejects Windows reserved names and trailing dots/spaces in `src/brain79/core/wiki.py`.
  - Catches hostile decode errors cleanly during scanning in `src/brain79/core/migration.py`.
- Introduces transactional Pass 3 session commits in `src/brain79/core/session_commit.py` with pre-mutation filesystem snapshot and automatic all-or-nothing rollback on `BaseException` (`KeyboardInterrupt`, `ENOSPC`).

### 3. Five-archetype battle gauntlet and latency budgets
- Implements complete 10-step lifecycle runner (`scripts/run_battle_gauntlet.py`) and test suite (`tests/test_battle_gauntlet.py`) across five workspace archetypes:
  - Archetype 1: dirty polyglot monorepo (Python, TS, binaries, ignored `.venv/node_modules/dist`).
  - Archetype 2: chaotic legacy wiki with zero data loss guarantee, Husky hook preservation, and stale MCP configuration replacement.
  - Archetype 3: gitless research workspace (`--profile general`, 10 consecutive sessions, Amnesia Test enforcement, and clean non-git handoff freshness).
  - Archetype 4: Git branch warfare (`main`, `feat/payments`, `hotfix/auth`), cross-branch handoff detection, and AST Guard C signature validation blocking bypass via `verified_articles`.
  - Archetype 5: scale benchmark (200 articles, 1,000 source files) verifying in-process median latency ceilings (`orient <= 500 ms`, `lint --strict <= 1,500 ms`, `doctor <= 1,500 ms`) with `BRAIN79_PERF_FACTOR` scaling.
- Expands `scripts/benchmark_baseline.py` with `calibrate_gauntlet_budgets()` to calibrate real-hardware baselines.

### 4. Live-agent recovery smoke testing
- Expands `scripts/run_e2e_smoke.py` with scenario 5 (`unresolved_session_ripple`) and scenario 6 (`duplicate_governance_target`).
- Enforces model policy (`gemini-3.8-flash:low`), returns exit code 77 when no agent CLI is installed, and verifies autonomous recovery from rejection without prompt hints.
- Records smoke run parameters and validation criteria:
  - Agent CLI: `pi` / `agy`
  - Model: `gemini-3.8-flash` (thinking effort: `low`)
  - Date: `2026-11-17`
  - Scenario 5 (`unresolved_session_ripple`): autonomous recovery verified across attempts (initial commit rejected, umbrella article incorporated on second commit, zero third attempt, strict lint clean).
  - Scenario 6 (`duplicate_governance_target`): autonomous recovery verified across attempts (initial commit rejected, governance target disambiguated on second commit, zero third attempt, strict lint clean).
