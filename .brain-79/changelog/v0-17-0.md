# Changelog — v0.17.0

**Release date**: 2026-11-27

## Highlights

- **Longitudinal anti-rot benchmark harness and release gate (`Phase 16`, `SPEC-016`)**: shipped the 12-session cold-start dual-arm benchmark (`benchmarks/anti_rot/`, `scripts/run_anti_rot_benchmark.py`) and verified `AC-6` `PASS` (7/7 criteria, exit `0`) on `gemini-4-hydrogen-low` (`0.0%` rot vs `1.12%` Arm B, `100.0%` canonical `src/**` coverage vs `50.0%`, `5.9x` fewer doc-read tokens, `12/12` compliance, `24/24` blind semantic recall).
- **Governance-complete bootstrap and template parity (`SPEC-202611`)**: `auto_map: bool | None = None` defaults to `True` for `software` wikis (`--no-auto-map` opt-out), with disjoint `applies_to:` examples, `Active Schema Summary` strict-required indicators, and public-signature/constants guidance.
- **Ergonomic `brain79_read_batch` and CLI/MCP parity**: added `paths=[...]` and string-item `requests` normalization across `read_batch_articles()`, `brain79_read_batch()`, and `brain79 read-batch --paths`, keeping a flat non-`anyOf` wire schema, `MCP_TOOLS == 9`, and `WHITELIST == 26`.
- **Strict-mode pre-flight parity**: aligned `commit_session()`, `write_article()`/`brain79_edit`, `write_many_articles()`, and `check_file_health()` 1:1 with `check_unanchored_governance()`.
- **Clean `orient()` and `context.py` ranking**: excluded `INDEX.md`/`SCHEMA.md` before `top_n`, prioritized active articles over `INACTIVE_STATUSES`, and appended bounded (`<= 20`) `brain79_read_batch(paths=[...])` reminders.
