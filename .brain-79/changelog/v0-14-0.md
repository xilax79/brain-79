# Changelog — v0.14.0

**Release date**: 2026-11-23

## Highlights

- **Focused 9-tool MCP surface (`SPEC-013`, `ADR-020`)**: pruned 13 redundant/administrative MCP wrappers (`brain79_index`, `brain79_schema`, `brain79_write`, `brain79_write_many`, `brain79_list`, `brain79_ingest`, `brain79_handoff_read`, `brain79_handoff_write`, `brain79_handoff_purge`, `brain79_navigate`, `brain79_migrate`, `brain79_update_project`, `brain79_doctor`), `ADMIN_TOOLS`, and dual-profile branching (`create_mcp_server(profile=...)`).
- **Retained `MCP_TOOLS`**: `brain79_orient`, `brain79_session_commit`, `brain79_read`, `brain79_read_batch`, `brain79_edit`, `brain79_context`, `brain79_search`, `brain79_lint`, `brain79_bootstrap`.
- **CLI superset preserved**: all 24 CLI subcommands in `WHITELIST` remain intact with unchanged flags and POSIX exit codes.
- **Profile flag removal**: `--mcp-profile` emits a `v0.14.0` migration error to `stderr` and exits `2`; `BRAIN79_MCP_PROFILE` is silently ignored on stdio startup to keep MCP handshakes clean.
- **Templates and docs synced**: updated `AGENTS.md`, `SKILL.md`, `SCHEMA.md`, `SCHEMA_GENERAL.md`, `README.md`, `USER_GUIDE.md`, `ARCHITECTURE.md`, and `CHANGELOG.md`.
