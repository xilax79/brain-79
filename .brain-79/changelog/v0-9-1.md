# Changelog — Release 0.9.1: Antigravity plugin, progressive disclosure, and root walk

Release v0.9.1 introduces the native Antigravity workspace plugin, progressive disclosure splitting of AGENTS.md into an on-demand skill, and dynamic ancestor root discovery.

---

## Key additions and enhancements

### 1. Native Antigravity workspace plugin
- Scaffolds `.agents/plugins/brain79/plugin.json`, `.agents/plugins/brain79/mcp_config.json`, and `.agents/plugins/brain79/skills/brain79-wiki/SKILL.md`.
- Preserves custom user fields in `plugin.json` (such as `"disabled"`) and third-party tools in `mcpServers`.
- Retains legacy `.agents/mcp_config.json` for backward compatibility across existing environments.

### 2. Progressive disclosure for agent instructions
- Compacts root `AGENTS.md` to <= 6,500 bytes to fit comfortably within agent context budgets.
- Preserves all mandatory protocol anchors (`<!-- brain79:start -->`, `# Brain-79 AI memory protocol`, `pi-mcp-adapter`, `brain79_index`, `No-Op Idempotence`, `Zero-Modification Rule`, `## Project notes`).
- Houses complete CLI/MCP operation matrices, JSON examples, and governance guides in the on-demand `brain79-wiki` skill.

### 3. Dynamic ancestor root resolution
- Leaves project root unset during flag parsing when `--project-root .` or `--project-root=./` is passed, allowing `get_project_root()` to climb upwards to an ancestor `.brain-79/`.
- Respects nested repository `.git` boundaries and explicit `BRAIN79_PROJECT_ROOT` environment configuration.
- Guarantees `brain79 init` without `--project-root` creates a local `.brain-79/` without ascending into parent directories.

### 4. Doctor diagnostics and repair parity
- Validates `.agents/plugins/brain79/` configuration and reports warnings if legacy configurations exist without the native plugin.
- Incorporates `.agents/plugins/brain79` in the `--fix` dirty-tree git guard.
- Automatically repairs missing or malformed plugin files via `brain79 doctor --fix`.
