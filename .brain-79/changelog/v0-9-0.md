# Changelog — Release 0.9.0: Project upgrade, multi-harness zero-config, and doctor diagnostics

Release v0.9.0 introduces the project protocol upgrader and multi-harness diagnostic engine, resolving the split-brain template skew across existing repositories.

---

## Key additions and enhancements

### 1. Delimited managed blocks in `AGENTS.md`
- Core instructions are wrapped inside `<!-- brain79:start v0.9.0 -->`...`<!-- brain79:end -->`.
- `sync_agents_manifest` parses and updates only the managed block, preserving 100% of custom persona directives before the block and project notes after the block.
- Delimiter corruption guard rejects mismatched or duplicated markers before touching disk.

### 2. Non-destructive `SCHEMA.md` synchronization
- Elevates schema version to `schema_version: 2`.
- Preserves `profile` (`software` or `general`), `custom_types`, and custom YAML fields in frontmatter.
- Preserves user-authored trailing sections (`## Project-specific schema extensions`).

### 3. Portable Tier 1 multi-harness MCP setup
- Deterministically generates and synchronizes `.mcp.json`, `.agents/mcp_config.json`, and `.cursor/mcp.json`.
- Enforces portable `"command": "brain79"` without machine-specific absolute binary paths.
- Performs non-destructive JSON merges with automated `.bak` backups on corrupted files.
- Provides opt-in Tier 2 registration for host desktop clients (Claude Desktop, Windsurf) with scoped names (`brain79-<project_name>`).

### 4. Respectful Git hook integration
- Detects existing third-party Git hook managers (Husky, Python `pre-commit`, Lefthook) and preserves them without overwriting.

### 5. Deterministic wiki reconditioning (`migrate_wiki` v2)
- Replaces blind early-exit with full-pass article validation across all wiki articles.
- Auto-completes missing required fields, repairs footer backlinks, and normalizes bullet colons.
- Degrades structurally incomplete active articles to `status: legacy` / `stability: legacy` so strict linter checks do not block the project.
- Supports `--commit-transition` for maintaining unbroken handoff freshness under ADR-016.

### 6. Subsecond diagnostic engine (`brain79 doctor`)
- Evaluates 7 operational categories in $<50\text{ ms}$: binary/environment, protocol sync, wiki structure, MCP harnesses, filesystem locks, git hooks, and handoff hygiene.
- Standard POSIX exit codes `0` (ok), `2` (warning), and `1` (error).
- Formatted text and JSON output modes.
- Git-aware `--fix` safety guard blocking execution if uncommitted protocol files exist.

### 7. 1:1 CLI and FastMCP symmetry
- Standardized 24 CLI subcommands and 22 MCP tools in strict 1:1 parity.
