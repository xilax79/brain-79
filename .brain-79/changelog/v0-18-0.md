# Changelog — v0.18.0

**Release date**: 2026-11-27

## Highlights

- **External `.brain-79/drift.lock` & hash-free frontmatter (`Phase 17`, `SPEC-017`, `ADR-023`)**: relocated machine-managed `applies_to_digest`, `applies_to_count`, and leaf `targets` into a single Git-tracked, LF-only, sorted-key JSON lockfile (`version: "2.0"`) guarded by `_drift_lock.lock` in `LOCK_HIERARCHY` and preserved by `cleanup_legacy_inline_locks()`.
- **3-way `brain79 merge-drift-lock` driver (`core/drift_merge.py`)**: expanded CLI `WHITELIST` from 26 to 27 commands (`MCP_TOOLS` remains 9), resolving disjoint, identical, and 0-byte-`<base>` merges cleanly (`Exit 0`), reverting same-key modify/modify and delete/modify conflicts to `base[k]`, and emitting `"conflict": true` sentinels on conflicting `add/add` keys.
- **Zero-diff `verified_articles` & Guard C baseline integrity**: `verified_articles` updates only `.brain-79/drift.lock` without dirtying `.md` files (blocking `"conflict": true` with `verified_article_conflict_forbidden`); shared `resolve_article_baseline_commit()` skips pure migration commits and falls back to article-only history beyond 50 lockfile commits.
- **Dual-read compatibility, `doctor`, and zero-masking migration**: `check_article_drift()` supports `drift.lock` -> legacy frontmatter + read-only `.drift_manifest.json` -> `last_updated`; `init`, `update-project`, and `doctor --fix` order `!drift.lock` after `*.lock`, register `brain79-drift-lock`, update `.git/hooks/pre-commit`, and migrate legacy digests idempotently without masking drift; `lint` emits `INFO` `legacy_frontmatter_digest` when unmigrated articles coexist with `drift.lock`.
- **CI matrix reliability & Windows SLA-1 recovery**: gated `.mjs` Guard C fixture checks on optional `polyglot` availability, enabled `include-hidden-files: true` + `if-no-files-found: ignore` for `.pytest_tmp` failure uploads, and eliminated `rebuild_drift_manifest()` calls during `orient()` when `drift.lock` covers active articles.
