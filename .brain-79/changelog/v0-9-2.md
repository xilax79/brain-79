# Changelog — Release 0.9.2: Zero-clone installation, CLI/Python 3.11+ alignment, and 3-layer Diátaxis documentation

Release v0.9.2 introduces zero-clone tool installation and self-updating from upstream Git, holistic alignment on Python 3.11+, and a clean 3-layer Diátaxis Markdown documentation structure while retiring HTML docs.

---

## Key additions and enhancements

### 1. Zero-clone tool distribution and self-update
- Enables `brain79 update` to detect standalone installations in `site-packages` and upgrade them via `uv tool install --force git+https://github.com/xilax79/brain-79.git`.
- Preserves local editable development checkouts by running `git pull --ff-only` followed by `uv tool install --editable --force .`.
- Adds branch override support (`--branch`) and handles running-process file lock errors on Windows gracefully.
- Prevents false-positive `.git` matches from user `$HOME/.git` dotfiles repositories.

### 2. Holistic CLI and Python 3.11+ alignment
- Aligns minimum Python runtime requirement to 3.11 across `doctor.py`, `templates/AGENTS.md`, and documentation.
- Updates `brain79 update` description and `--branch` help text to reflect tool binary updates.
- Expands `ROOT_HELP` in `__main__.py` to list `update-project` and `doctor` alongside `update`.
- Updates missing binary hints in `doctor.py` and `AGENTS.md` to recommend zero-clone installation.

### 3. Three-layer Diátaxis documentation structure
- Rewrites `README.md` as a concise, human-facing landing page (~138 lines) in clean B2 English with an ASCII workflow diagram and day-to-day usage guide with zero internal engine jargon.
- Creates `USER_GUIDE.md` as an in-depth How-To and protocol reference covering AGENTS.md + MCP integration, 5 concrete code-verified scenarios (cold-start orientation with 64 KB reading manifest, AST Guard C and Ripple Gate stale doc protection, gitless research, on-demand handoffs, and MCP/CLI reference table).
- Updates `ARCHITECTURE.md` with complete 28-file module map, verified traces of `orient()` and `commit_session()`, and cross-platform concurrency invariants.
- Retires HTML documentation files (`docs/whitepaper.html` and `docs/index.html`) in favor of pure, zero-dependency Markdown documentation.
