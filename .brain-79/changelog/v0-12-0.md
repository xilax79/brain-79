# Changelog — v0.12.0

## Summary

`v0.12.0` removes public-release friction and reduces per-turn LLM token overhead prior to public preview:

- **English-first backlinks**: replaced `[← Volver al Índice]` with `[← Back to Index]` (`DEFAULT_BACKLINK_LABEL`), added optional `backlink_label:` in `SCHEMA.md`, preserved backward-compatible lint recognition of legacy Spanish footers, and enabled deterministic idempotent canonicalization in `migrate_wiki()`.
- **Native multi-harness instruction adapters**: extracted shared delimited block engine (`core/harnesses/_delimited.py`), added compact `HARNESS_COMPACT.md` template, and registered `ClaudeCodeAdapter` (`CLAUDE.md`), `CursorRulesAdapter` (`.cursor/rules/brain79.mdc`), and `CopilotAdapter` (`.github/copilot-instructions.md`). Added `--harnesses` selective install on `brain79 init` and full `doctor` diagnostics and dirty-tree guards.
- **MCP tool surface compaction (`core` default)**: compacted `CORE_TOOLS` to 8 hot-path tools and switched default FastMCP server profile from `full` (22 tools) to `core` (~64% schema reduction per turn), with `BRAIN79_MCP_PROFILE` env var support, CLI `--mcp-profile` precedence, and profile-tailored instructions.
- **Honest positioning**: added `## Limitations and trade-offs` to `README.md` and clarified ADR-017 pre-GA (`0.y.z`) versioning in `CHANGELOG.md`.
- **Windows CI `orient()` hot-path optimization**: memoized contained path resolution in `WorkspaceIndex`, replaced `copy.deepcopy()` in `_PARSE_CACHE` with `_clone_yaml_value()`, and shared `GitSessionCache` across `orient()` sub-calls.
