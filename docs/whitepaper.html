The Problem: Organic AI Decay

AI agents generate high-quality prose, but across multiple sessions they degrade knowledge organically:

  • Amnesia: Every session re-reads files from scratch, burning token budgets.
  • Hallucinated References: Agents invent dead markdown links and phantom folders.
  • Decision Clutter: Architecture choices get lost inside general conversation logs.
🛡️

The Solution: Deterministic Memory

brain-79 treats memory like compiled software code rather than an unstructured pile of notes:

  • Dual-Memory Hierarchy: Clear separation of tactical handoffs vs. permanent wiki.
  • Mechanical Linters: Rejects broken links and missing frontmatter at write-time.
  • Sub-second Orientation: Agent reads INDEX.md and knows the state in 1 turn.
